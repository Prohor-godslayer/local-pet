# Локальный питомец

Несколько питомцев на чат. Голод, энергия, чистота и настроение считаются по часам устройства, с догоном после простоя. Есть рост, привычки, реакция на сцену и уход. Наблюдатель спрашивает модель, которая уже настроена в клиенте.

Состояние лежит в файле настроек и в файле чата. Выгрузка и загрузка — JSON на вашем устройстве.

## SillyTavern

Скопируйте репозиторий в `data/<пользователь>/extensions/local-pet`. Панель: кнопка у края чата и пункт «Локальный питомец».

## Tavo

Импортируйте `tavo/local-pet.tpg`.
