# Локальный питомец

Версия 1.1.0. Несколько зверей на чат. Голод, энергия, чистота и настроение идут по часам устройства, даже когда клиент закрыт. Наблюдатель, если он включён, спрашивает модель, которая уже настроена в SillyTavern или Tavo.

Из кода расширения наружу ничего не уходит. Кнопка обновления в Таверне — это её `git pull` этого репозитория.

## Установка в SillyTavern

Кнопка «надо обновить» появляется только у установки из git. Скопированная папка её не получит.

1. «Расширения» → «Установить расширение».
2. Адрес: `https://github.com/Prohor-godslayer/local-pet`. Ветка `main`.
3. После загрузки открой «Управление расширениями». Карточка «Локальный питомец», версия 1.1.0.
4. Включи «Уведомлять об обновлениях расширений», если пункт есть.

Кнопка 🐾 у края чата перетаскивается. Пункт меню называется «Локальный питомец».

Старую папку без git в `data/<пользователь>/extensions/local-pet` удали и поставь заново по ссылке.

### Когда Таверна говорит, что нужно обновить

В манифесте `"version": "1.1.0"` и `"auto_update": true`. Таверна сравнивает локальный коммит с `origin/main`. Если GitHub впереди, на карточке есть кнопка. По-английски это **Update available**, по-русски — перевод из языкового пакета. Нажатие делает `git pull`. Версию после этого снова смотри в карточке.

## Установка в Tavo

1. Скачай `tavo/local-pet.tpg`: https://github.com/Prohor-godslayer/local-pet/blob/main/tavo/local-pet.tpg
2. Импортируй файл как плагин. Сетевого права нет. Нужны ввод, сообщения, переменные, файл и генерация.
3. Открытие: кнопка 🐾, действие ввода «Локальный питомец», боковая панель.

Новую версию Tavo сам не подтянет. Скачай свежий `.tpg` и импортируй снова. Версия плагина 1.1.0.

## Как пользоваться

100 по шкале значит «хорошо»: сыт, бодр, чист. Ноль — плохо.

1. «Новый». Имя, кто это словами («рыжий кот», «пёс», «хорёк»), нрав, чей зверь (мой, персонажа, общий) и значок. Порода для скорости голода угадывается по этим словам.
2. В карточке: покормить, играть, мыть, гладить, гулять, уложить или разбудить. Игра при энергии ниже 15 не начинается, панель так и пишет.
3. Три одинаковых заботы подряд становятся привычкой: еда из рук, сам несёт игру, не прячется от мытья.
4. «Спросить модель, что он делает» один раз вызывает модель клиента. Пустой ответ и ответ со словами вроде «промпт» или «модель» выбрасываются, остаётся своя строка поведения.
5. «Настройки». Галочка «Отдавать состояние в промпт» кладёт короткое описание в системный кусок перед ответом, без просьбы озвучивать цифры. «Модель-наблюдатель» раз в N сообщений сам спрашивает модель про активного зверя. Пока она думает, новое сообщение в чат лучше не слать: обработчик на это время молчит, чтобы не вызвать её второй раз.
6. Сцена сама дёргает зверя: кухня и ужин, гроза, дверь, ссора, объятие, сон. Повтор одного типа не чаще раза в 10 минут. Спящий и больной на текст не реагируют.
7. Если зверя не касались 8 часов и больше, при следующем отсчёте растёт обида и чуть падает привязанность. Короткий простой обиду не включает. Отсутствие длиннее 14 суток считается как 14 суток.
8. «Скачать файл» сохраняет всех зверей всех чатов в JSON на диск. «Вложить файл» читает такой JSON обратно. Это и есть перенос на другое устройство.
9. «Убрать из чата» удаляет только этого зверя из текущего чата.

Рост по прожитым часам: детёныш, подросток (72 ч), взрослый (240 ч), пожилой (1440 ч). Подписи привязанности: чужой, привык, друг, предан, неразлучны.

## Где лежат данные

Один объект на всех чатов. SillyTavern пишет его в `settings.json`, ключ `local_suite_pet`. Tavo пишет `lx_pet_db` в файл плагина, затем в глобальную переменную и `localStorage`.
